# 8x8 LED Matrix Ideas

Based on GitHub projects and community resources for the H31-64wei-deng 8x8 WS2812 matrix mounted at 45°.

## Perfect for the 45° Diamond Shape

| Idea | Description |
|---|---|
| **Animated Eye** | Blink, look around, expressions (implemented) |
| **Pixel Face** | Simple emoticons on single 8x8 |
| **Magic 8-Ball** | Swirling "cosmic" animation, then reveal answer text |
| **Crystal Ball** | Pulsing colors inside the diamond, fortune-telling effect |
| **Spinning Compass** | N/S/E/W arrow rotating inside diamond |
| **Fish / Swimming** | Small fish sprite swimming across the diamond |
| **Heartbeat** | Animated heart that pulses (valentine effect) |

## Classic 8x8 Effects (any orientation)

| Idea | Description |
|---|---|
| **Audio VU Meter** | Mic input → bouncing bars or color wave |
| **Weather Icons** | Sun, rain, clouds, snowflake pixel art (rotates with forecast) |
| **Notification Badge** | Email icon, WiFi strength, alert patterns |
| **Simple Games** | Snake, Pong (single-player), Tetris drop |
| **Binary Clock** | Each pixel = 1 bit, hours/min/sec in rows |
| **Pixel Art Slideshow** | Cycle through sprites (Space Invaders, Pac-Man, Mario) |
| **Fireplace** | Simplified fire effect |
| **Lava Lamp** | Bubbles floating up |
| **Game of Life** | Conway's cellular automata |
| **Color Organ** | 3 frequency bands mapped to RGB |
| **Message Scroller** | Horizontal scrolling text, 1 char at a time fits in 8x8 |

## Combined with ESP32 WiFi

| Idea | Description |
|---|---|
| **Network Monitor** | Ping response = green flash, timeout = red |
| **Stock / Crypto Ticker** | Green/red pixel pulse for price changes |
| **Doorbell Indicator** | Flash pattern when someone rings |
| **Sunrise Alarm** | Gradual warm-up from dark to bright warm white |
| **Mood Light** | REST API to set color/pattern from Home Assistant |
| **Countdown Timer** | Pixels disappearing one by one |
